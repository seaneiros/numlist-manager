# Задача

Разработать приложение для работы со списком из **1 000 000** элементов с ID от `1` до `1 000 000`.

Приложение должно позволять выбирать элементы, фильтровать их и изменять порядок выбранных элементов.

## Функциональные требования

### 1. Интерфейс

Интерфейс должен состоять из двух контейнеров:

- **Левый контейнер** — содержит все элементы, кроме выбранных.
- **Правый контейнер** — содержит выбранные элементы.

### 2. Левый контейнер

Необходимо реализовать:

- фильтрацию элементов по ID;
- бесконечную прокрутку:
  - при первоначальной загрузке отображается не более 20 элементов;
  - следующие элементы загружаются порциями по 20;
- добавление новых элементов:
  - ID задается пользователем вручную;
  - значение ID может быть произвольным;
  - повторное добавление существующего ID не допускается.

### 3. Правый контейнер

Необходимо реализовать:

- фильтрацию выбранных элементов по ID;
- изменение порядка элементов с помощью Drag & Drop;
- работу Drag & Drop в том числе при активной фильтрации;
- бесконечную прокрутку:
  - при первоначальной загрузке отображается не более 20 элементов;
  - следующие элементы загружаются порциями по 20;
- сохранение выбранных элементов и их порядка после обновления страницы.

> Значения фильтров после обновления страницы сохраняться **не должны**.

### 4. Хранение данных

- Состояние выбора и порядок элементов должны храниться на сервере.
- Использовать базу данных не требуется — достаточно хранения в оперативной памяти на протяжении времени работы приложения.
- Учётные записи и авторизация не требуются.
- Данные могут быть общими для всех пользователей приложения.

### 5. Фильтрация и пагинация

При использовании фильтра:

- одновременно должно отображаться не более 20 элементов;
- дополнительные результаты должны загружаться при прокрутке;
- размер каждой следующей порции — 20 элементов.

### 6. Работа с большим количеством запросов

Система должна учитывать возможность одновременного поступления большого количества запросов.

Необходимо реализовать:

- очередь обработки запросов;
- дедупликацию запросов;
- техническую гарантию того, что одно и то же значение не будет добавлено повторно;
- батчинг операций добавления элементов — один раз в 10 секунд;
- батчинг операций получения и изменения данных — один раз в секунду.
